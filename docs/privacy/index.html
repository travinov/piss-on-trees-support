Эта страница описывает текущую тестовую версию Piss on Trees 0.2.22 для iPhone и iPad. Основная игра работает локально; онлайн-рекорды через Apple Game Center необязательны.

Прогресс и свои парки

Настройки, сохранённая прогулка, локальные рекорды, журнал попыток, импортированные карты и их изображения хранятся в данных приложения на устройстве. В игре нет собственного сервера аккаунтов или загрузки парков разработчику.

Импорт обрабатывает выбранный тобой файл карты. Передавая его через другие приложения, ты выбираешь получателей самостоятельно. Возможные системные резервные копии регулируются настройками устройства и iCloud.

Необязательные онлайн-рекорды

При подключении Game Center приложение использует игровой идентификатор и псевдоним Apple, связывает очередь очков с этим игроком и передаёт счёт завершённой встроенной кампании. Свои парки и гостевые прогулки не отправляются в таблицу. При ошибке очередь хранится локально для повторной отправки тем же игроком.

В общей таблице псевдоним и очки могут быть видны другим игрокам. Apple управляет Game Center по своей политике Game Center.

Отключить будущие отправки можно в «Рекордах» кнопкой «Выключить онлайн-рекорды». Это не удаляет уже отправленные Apple результаты. Настройками профиля и данных Apple управляй через Game Center и Apple Account.

Тестирование через TestFlight

Для тестовой установки используется Apple TestFlight. Apple обрабатывает сведения об установках, сеансах, сбоях и добровольно отправленных отзывах и предоставляет разработчику доступные отчёты тестирования. Присланные тобой снимки экрана и комментарии используются для исправления ошибок.

Подробности доступны на странице Apple TestFlight. Участие в тестировании можно прекратить в TestFlight.

Ссылки на объектах парка

Пользовательская карта может содержать внешние ссылки. Перед переходом игра показывает адрес и запрашивает подтверждение. После перехода выбранный сайт может получать IP-адрес и другие обычные сведения браузера; на нём действуют собственные правила обработки данных.

Обращения в поддержку

Если ты отправляешь письмо или отзыв, разработчик получает твой адрес, текст и добровольно приложенные файлы. Они используются для ответа и диагностики. Переписка хранится, пока нужна для решения вопроса; запросить удаление можно через тот же канал связи.

Контакт: pissontreesgame@gmail.com. Разработчик не имеет удалённого доступа к сохранениям на твоём устройстве.

Обращения через GitHub публичны и обрабатываются по политике GitHub. Для личных сведений используй TestFlight.

Этот сайт и аналитика

В игре нет рекламных или сторонних аналитических SDK. Этот сайт не использует аналитические скрипты, рекламные cookies, формы загрузки и localStorage. Кнопка копирования адреса обращается к буферу обмена только по твоему нажатию.

Сайт размещён на GitHub Pages. GitHub сохраняет IP-адреса посетителей для безопасности сервиса: информация GitHub Pages.

Удаление и твой выбор

Карты можно удалить в «Моих парках». Удаление приложения средствами iOS может удалить оставшиеся локальные данные. Экспортированные файлы, системные резервные копии, письма и данные у Apple управляются отдельно в соответствующих сервисах.

Для локальной игры Game Center не требуется. Отключение онлайн-рекордов запрещает новые отправки, но не удаляет уже переданные Apple данные. При изменении функций эта страница обновляется.
